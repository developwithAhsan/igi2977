BROWSER PLAY GUIDE

How the Project I.G.I. browser edition works

Project I.G.I. Online is a fan-made browser interface for the original Project I.G.I.: I'm Going In, the tactical first-person shooter released in 2000. It is designed to let a player use a compatible browser to run a port of the game without installing a separate desktop launcher. The browser experience is not a cloud game streamed from a server: you provide the game data that you already own, and the browser uses that local data to run the port.

1. Prepare your own game copy

Before starting, locate a legally obtained copy of Project I.G.I. on your device. The browser page does not provide a download link for the commercial game and does not contain the original game data. When the launcher asks you to choose a folder, select the folder containing the installed game files. The first import can take time because the browser needs to copy a large collection of files into its private origin storage. The exact size depends on the copy you provide; do not assume the website will fetch the files for you.

2. Import once and keep browser storage intact

The port uses browser storage to keep the imported files available for later sessions. The import is performed locally by the browser and the selected game data is not uploaded to this website's server. If you clear site data, use a private browsing session, or let the browser evict stored data, you may need to import your own game folder again. Keep a separate backup of your original installation. Do not share your game folder or copyrighted files with other people unless you have the right to do so.

3. Start the game after the browser checks

Once the launcher finishes checking the browser and preparing the runtime, continue to the game menu and choose Play. The first start can take longer than later starts because the runtime has to initialize the game and load its resources. A black or temporarily inactive game view during initialization does not necessarily mean the page has stopped; wait for the visible status or loading indicator to change. If an error appears, note the exact message before refreshing.

4. Choose the input method that matches your device

On a desktop, the port provides keyboard and mouse input, with configurable bindings and sensitivity controls. The controls panel beside the game lists the available settings. On supported touch devices, the project includes an on-screen control layout with a virtual movement stick and action buttons. The touch interface also includes configurable layout options. Device compatibility depends on browser support, available memory and graphics hardware; the presence of a touch interface does not guarantee that every phone or tablet can run the game smoothly.

5. Use gyro aiming only where supported

The project includes gyroscope aiming options for compatible devices and browsers that expose motion sensors. Motion access may require a browser permission or a user gesture, and some platforms restrict sensor access. If the gyro option is unavailable or does not respond, use touch swipe aiming instead. You can review the keyboard, mouse, touch and gyro controls guide for a summary of the options documented by this build.

6. Understand widescreen behavior

The build includes a widescreen display option. The game adjusts its viewport and field of view for wider windows while keeping certain 2D menus and scoped views in their intended proportions. Widescreen behavior can differ between the main 3D view, menus and scope overlays. If the image looks stretched or cropped, check the display setting and compare it with the default mode before changing browser zoom.

7. Troubleshoot without losing your imported files

If the game does not start, first check that your selected folder is the correct installation and that the browser supports WebAssembly and WebGPU. Close other memory-heavy tabs and applications, update the browser, and avoid opening multiple game sessions at once. If the browser reloads after a crash, it may have run out of memory or lost its graphics device. Preserve the browser's site data while troubleshooting; clearing storage can remove the imported copy and force another import.

8. Know what this website does and does not provide

This is an independent fan project. It is not an official release, is not affiliated with or endorsed by Innerloop Studios or Eidos Interactive, and does not distribute the original game. The browser port, page layout and setup guides are provided as a way to use your own game data in a compatible environment. Availability and performance can change with browser updates, operating-system policies and device hardware. For privacy and storage details, read the Project I.G.I. browser safety guide and the privacy policy.

9. Is this Project I.G.I. 1 or IGI 3?

This page runs the original Project I.G.I.: I'm Going In, released in 2000. It is not Project I.G.I. 2: Covert Strike and it is not I.G.I. Origins. The project commonly discussed as the third entry was announced under the name I.G.I. Origins, but it is not the 2000 game running here. Read the IGI 3 release and identity explainer for the distinction.

10. Start with the right guide

Use the live controls panel for current in-game bindings, the frequently asked questions for common setup questions, and the contact page to report a technical issue. If you are ready to launch, return to the game window above and import your own game folder when prompted.

02 / ABOUT THE GAME

Enter the world of Project I.G.I.

Project I.G.I.: I'm Going In is a first-person tactical stealth shooter originally released in 2000. You play as David Jones, a former SAS soldier working through high-risk missions that reward observation, planning and controlled action.

Use the environment, long-range weapons, equipment and careful movement to infiltrate enemy positions. Its large outdoor areas and mission-based structure helped make it a memorable PC shooter.

05 / TIPS & TRICKS

Practical Project I.G.I. mission tips
  • Study the area before moving into an exposed position.
  • Use cover and avoid unnecessary noise when possible.
  • Keep an eye on ammunition and reload between encounters.
  • Use long-range optics to assess distant threats.
  • Rebind keys if the default layout does not suit your setup.
  • Close memory-heavy browser tabs if performance becomes unstable.
  • Use landscape mode and a physical keyboard for desktop-style play.
  • Keep browser storage intact if you rely on locally saved data.
